# MambaCAFU: Hybrid Multi-Scale and Multi-Attention Model with Mamba-Based Fusion for Medical Image Segmentation

This is the official implementation of our proposed medical imaging segmentation architecture MambaCAFU officiel pytorch implementation is available at networks folder with training and evaluation codes for Synapse, BTCV, ACDC, ISIC17, GlaS and MoNuSeg.
